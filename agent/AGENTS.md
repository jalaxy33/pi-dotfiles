## Working rules

- Be brief and plain everywhere: replies, comments, and docs. No jargon, no invented terms.
- Write code and comments in English.
- Keep code plain and simple. Prefer direct constructs over clever tricks or abstraction.
- Before writing a one-off script (e.g. Python to batch-edit files), check codemode first: batch the tool calls there. Write a script only for real logic or work you will rerun.
- Keep comments short and specific; drop anything unrelated.
- Keep commit messages to one short sentence; add a body only when necessary.
- Don't add tests unless they earn their place.
